// System Topology

4 Katmanlı Modüler Mimari

Çekirdek tarama motorundan masaüstü arayüzüne kadar tamamen ayrıştırılmış, genişletilebilir Python & Rust (Tauri) mimarisi.

LAYER 01

Provider Adapters

Robotistan, Direnc.net, Robolink, Robo90, Motorobit ve Özdisan için izole istemciler ve ortak BaseProvider sözleşmesi.

LAYER 02

Unified Core & Cart

Paralel sorgu birleştirme, eşanlamlı (synonym) genişletme, TTL önbellek ve kargo eşiği bazlı sepet optimizasyon motoru.

LAYER 03

AI Agent & FastAPI

5 aşamalı otonom BOM pipeline'ı, çoklu LLM sağlayıcı soyutlaması ve yüksek performanslı RESTful API sunucusu.

LAYER 04

Delivery Surfaces

Tauri Cross-Platform Desktop App, Rich CLI, MCP Sunucusu, Telegram Botu ve Docker Compose dağıtımı.

Hızlı Başlangıç

Python SDK & CLI 
# Kurulum (Agent + API + MCP dahil)
pip install "robo-market-search[all]"

# Terminalden anında arama
robo-market search "esp32 cam" --limit 5

# AI Ajanı ile proje analizi
robo-market-agent plan "Güneş takip eden solar panel sistemi"
Docker & Web Studio 
# Tek komutla Full-Stack başlatma
git clone https://github.com/atacanymc/robo-market-search.git
cd robo-market-search
docker compose up -d

# API Docs: http://localhost:8000/docs
# Web UI:   http://localhost:3000
Homebrew (macOS & Linux) 
# Kurulum
brew install atacanymc/tap/robo-market-search

# Güncelleme
brew upgrade robo-market-search
