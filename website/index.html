Yetenekler

Akıllı Donanım Tedarik Altyapısı

Tek bir sorguyla en ucuz parçaları bulun, kargo maliyetlerini hesaplayın ve yapay zeka ile BOM listesi çıkartın.

🔍

Eşzamanlı Paralel Canlı Arama

Tüm marketlerde ThreadPool mimarisiyle saniyeler içinde paralel arama yapar. Sonuçlar en ucuzdan pahalıya sıralanır, stokta olmayan ürünler filtrelenebilir ve tek tıkla CSV/JSON formatında indirilebilir.

🛒

Akıllı Sepet & Kargo Bölüşümü (`cart_search`)

Birden fazla parça alırken her mağazanın ücretsiz kargo limitlerini (örn: 1500 TL barajı) analiz eder. Ürünleri tek mağazadan toplu almak mı, yoksa kargo baremlerine göre bölüşmek mi (split cart) daha karlı otomatik hesaplar.

🤖

BYOK Destekli Yapay Zeka Ajanı

Kendi API anahtarınızı (OpenAI, Gemini, Claude, DeepSeek, Groq, Ollama) bağlayın. "Otomatik sulama sistemi" gibi serbest metin proje tanımlarını anlar, Malzeme Listesi (BOM) çıkartır ve voltaj uyumluluklarını denetler.

⚡

Çoklu Arayüz & Terminal Araçları

Masaüstü uygulamasına ek olarak zengin terminal araçları (`robo-search`, `robo-agent`), Claude Desktop için MCP sunucusu (`robo-mcp`), Aiogram Telegram botu (`robo-bot`) ve FastAPI REST API (`robo-api`) içerir.

İndirme Merkezi

İstediğiniz Platformda Kullanın

macOS, Windows ve Linux için yerel masaüstü uygulaması veya terminal üzerinden Homebrew ve pipx kurulumu.

macOS Masaüstü (.dmg)

Apple Silicon (M1/M2/M3/M4) ve Intel Mac'ler için yerel Tauri v2 uygulaması.

Apple Silicon İndir (.dmg) Intel Mac İndir (.dmg)

Homebrew ile Kurulum

Terminal üzerinden tek satırla global CLI aracını kurun.

brew install atacanymc/tap/robo-market-search
robo-search "ESP32"

Windows Masaüstü (.msi)

Windows 10 ve 11 (64-bit) için yerel kurulum paketi ve masaüstü arayüzü.

Windows Yükleyici İndir (.msi) Taşınabilir Sürüm (.exe)

pipx / pip ile Kurulum

PowerShell veya CMD üzerinden CLI komutlarını kurun.

pipx install "robo-market-search[all]"
robo-search "Arduino Uno"

Linux Paketleri

Ubuntu, Debian, Fedora, Arch ve diğer Linux dağıtımları için hazır ikili paketler.

AppImage İndir (.AppImage) Debian Paketi (.deb)

Hızlı Shell Kurulumu

Tek satır cURL betiği ile ortam yapılandırması gerektirmeden kurun.

curl -fsSL https://raw.githubusercontent.com/AtaCanYmc/robo-market-search/main/install.sh | bash

pipx (Tavsiye Edilen)

Global Python ortamınızı kirletmeden izole bir sanal ortamda CLI araçlarını kurar.

pipx install "robo-market-search[all]"

Modüler pip Kurulumu

Yalnızca ihtiyacınız olan katmanları bağımsız paketler olarak yükleyebilirsiniz.

pip install "robo-market-search[cli]"
pip install "robo-market-search[agent]"

Docker Compose ile Dağıtım

FastAPI REST API sunucusunu tek komutla sunucunuzda konteyner olarak çalıştırın.

git clone https://github.com/AtaCanYmc/robo-market-search.git && cd robo-market-search && docker compose up -d

Başlatıldıktan sonra: http://localhost:8000/docs

Geliştirici Odaklı

Hızlı Kod ve Entegrasyon Örnekleri

Kendi Python projelerinizde, terminal betiklerinizde veya LLM asistanlarınızda kullanın.

1. Python SDK (`UnifiedSearchClient`)

from robo_market_search import UnifiedSearchClient

client = UnifiedSearchClient()

# 6 mağazada eşzamanlı canlı arama
results = client.search("ESP32 DevKit", limit_per_store=3)

for product in results:
    print(f"[{product.store}] {product.name} - {product.price} TL (Stok: {product.in_stock})")

2. Claude Desktop MCP Yapılandırması (`claude_desktop_config.json`)

{
  "mcpServers": {
    "robo-market-search": {
      "command": "robo-mcp"
    }
  }
}
