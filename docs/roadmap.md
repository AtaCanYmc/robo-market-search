# Product Roadmap

This document outlines upcoming milestones and planned features for **Robo Market Search**.

---

## 🗺️ Roadmap & Milestones

### 🟢 Version 1.4.0 (Current Version)
- [x] Vite 6 + React 18 + Tailwind CSS Web UI (`demo/frontend`).
- [x] Bring Your Own API Key (BYOK) AI Hardware Agent.
- [x] Search Results Export (CSV, JSON, Markdown, Clipboard).
- [x] Single-command installers (`install.sh`, Homebrew Tap).
- [x] 1500 TL Default Free Shipping Thresholds in Cart Optimizer.
- [x] Enterprise-level Documentation Suite (`docs/`).

---

### 🟡 Version 1.5.0 (Upcoming)
- [ ] Additional Store Scrapers (`Motorobit`, `KartalOtomasyon`, `Ozdisan`).
- [ ] Price History Tracking & Alert Webhooks.
- [ ] Redis Distributed Caching Support for `robo_market_service`.
- [ ] WebSocket Live Streaming for Agent Analysis steps.

---

### 🔵 Long-Term Vision (v2.0.0)
- [ ] Automated Component Alternative Recommendation Engine.
- [ ] Native Mobile App (React Native / Expo).
- [ ] Multi-currency support (USD, EUR conversion).
